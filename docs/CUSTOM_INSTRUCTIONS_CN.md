# 推荐的全局自定义指令

自定义指令只保留跨所有任务都稳定成立的偏好。插件能力、技术规则、测试清单和示例放在 Skill 内，由轻量路由按需加载。

推荐内容：

```md
<!-- codex-full-zh-at-agent-selection start -->

# 中文与 Agent 选择

- 默认使用简体中文；代码、命令、文件路径、API、包名和框架名保持原文。
- 保留全部中文 `@` Agent，用户可手动选择。
- 只有用户明确要求“多个角色并行”时，选择最相关的 3–5 个角色；除非用户另有要求，不超过 5 个。
- 多角色结果必须去重、处理冲突并形成统一结论，不能简单拼接。
- 中文角色映射不确定时再查 TOML description 或 CSV，不在每轮预读完整映射。

<!-- codex-full-zh-at-agent-selection end -->
```

不应放入全局自定义指令：

- 每个 Agent 的调用示例；
- 所有原子 Skill 的触发词和完整目录；
- Unity、NodeTs、Web 等技术栈的长检查表；
- 项目专属架构、需求、接口和测试状态；
- 每轮都强制多 Agent、全量扫描或全量测试的要求。

这些内容会被每个新任务重复注入，既增加首轮选择开销，也容易与项目级 `AGENTS.md` 和 Skill 指令冲突。
