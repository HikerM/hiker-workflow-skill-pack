# 使用说明

## 智能软件工程平台

普通开发、架构、审核、测试、Git、多会话和发布请求由“智能工程轻量路由”自动进入。用户无需手动猜 Skill。ChatGPT 先显示轻量路由，再根据当前阶段显示最多两个实际应用的中文 Skill。

示例：

```text
接管这个已有项目。先识别真实前后端技术和版本，建立现有能力基线，再评估新增功能的影响范围；不要重建脚手架。
```

```text
这个功能反复修复后出现新旧实现并存。请找出唯一权威入口、状态写入者和迁移退出条件，再制定最小收敛方案。
```

```text
这是长寿命大型项目。只读取当前任务、有界差异、直接契约和消费者，不扫描全部历史与冷归档。
```

软件工程平台会按规模限制工作集，并在 `.ai` 与源码不一致时先分级恢复。没有证据的版本保持 unknown；没有影响范围、行为不变量和最低回归的任务不得直接编码。

## 桌面软件等价重建

必须明确选择“桌面软件等价重建”，并先确认授权边界。总路由只加载当前门禁的一个 Skill。

```text
使用“桌面软件等价重建”接管这个已授权项目。先完成发现与规格，不要提前选择框架或开始编码。
```

当发现、技术方案、实现或验证门禁未通过时，停留在当前阶段修复证据；不会同时加载全部参考和脚本。

## 回执规则

只显示实际应用的中文插件名称和中文 Skill 名称，不显示能力包组别、英文内部 ID、未使用项或冗长触发原因。阶段不变不重复显示；阶段切换或上下文恢复时重新显示。
