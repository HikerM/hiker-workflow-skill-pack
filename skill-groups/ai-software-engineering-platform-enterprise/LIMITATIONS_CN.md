# 能力边界与限制

1. Skill 可以指导 Codex 使用 Subagent 和 Worktree，但不能在普通 Chat 中自动创建并长期管理任意数量的独立会话。
2. 当前 Codex 插件 manifest 不支持本套件旧版使用的 `hooks` 字段；状态快照与恢复脚本不会自动注册，需由 Skill 或外部编排显式调用。
3. 官方规范解析需要当前客户端具备网络检索能力。离线时只生成待核验清单，不伪造“已查官方手册”。
4. Git Worktree 只适用于 Git 仓库。非 Git 项目会退化为单工作区模式。
5. 自动回滚默认关闭。系统保存检查点和 Git 基线，但破坏性恢复必须由用户明确要求。
6. SQLite 工程图谱默认建立文件级依赖，不替代编译器级完整调用图；高风险修改仍需构建和测试证据。
7. 本包通过本地结构、官方插件校验和脚本测试，但实际安装入口与 Subagent 可用性仍取决于账号和客户端版本。
8. 有界记忆保证关键工程事实落盘并可按优先级恢复，不保证逐字保存无限聊天历史。超过保留上限的冗余checkpoint副本会在写入有界索引、SHA-256与连续哈希链后移除；源码、Git提交、Task、正式决定和验收证据不在清理范围。
9. 同一已打开桌面任务持有创建时的插件能力快照，运行中的桌面进程也可能缓存插件注册表。新建任务是无重启热切换的验证边界，不是成功保证；若新任务仍命中旧缓存，必须重启应用。
10. 调度防重依赖桌面任务查询返回可区分的错误、超时和明确空结果；无法确认时会失败关闭，不会猜测任务不存在。
11. 敏感交接扫描不能替代组织级 DLP、密钥轮换或人工安全审核；发现可能泄漏的真实凭据时仍应立即撤销和轮换。
