# AI Software Engineering Platform Enterprise 4.0（架构收敛版）

这是面向 ChatGPT Work / Codex 桌面端的大型软件工程插件套件。它不再把所有能力堆进一个超长 Skill，而是拆成 5 个可独立启用的中文插件：

1. **AI工程核心**：项目识别、真实版本检测、项目专属规范、任务状态、压缩保护和恢复。
2. **B/S界面与前端工程**：通用 Web UI 设计、组件化实现、视觉与前端代码审核。
3. **Unity C/S工程**：Unity UI、Prefab、Renderer、资源、多分辨率和平台兼容。
4. **工作区与多会话协作**：Subagent 任务分流、Git Worktree、代码所有权和合并预检。
5. **质量、风险与发布**：完整本地变更集、SQLite 增量图谱、回归测试计划和发布证据。

## 关键约束

- **一次识别，多次复用**：领域插件读取 `.ai/context/`，不得重复全仓库技术栈分析。
- **持续执行但可随时中断**：用户说“暂停、调整、继续、回滚、查看状态”时，核心 Hook 更新运行状态，不要求每一步审批。
- **上下文压缩不作为记忆系统**：PreCompact 自动保存检查点；SessionStart 在启动、恢复和压缩后重新注入精简状态。
- **一个 Git 仓库，多 Worktree**：并行写任务使用独立 Worktree；只读探索优先使用 Subagent。
- **不把源码全文塞进知识图谱**：图谱使用 SQLite 存储文件级关系，增量更新、限深查询和节点上限。
- **证据优先**：未执行的测试只能标记为“计划”，不能写成“通过”。

## 推荐启用组合

- Web 项目：核心 + B/S + 工作区 + 质量
- Unity 项目：核心 + Unity + 工作区 + 质量
- Web + Unity 混合项目：全部 5 个
