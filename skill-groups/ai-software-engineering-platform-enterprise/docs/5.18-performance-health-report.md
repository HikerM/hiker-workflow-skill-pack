# Hiker 5.18 性能健康报告

本报告记录可重复的本地确定性测量。没有同场景5.17数据或没有实际执行的阶段统一标记为 `NOT_MEASURED`，不推断性能提升。

## 结论

- AI Freedom：`PASS`。Risk Profile不包含固定思考步骤；推理路径、实现顺序、设计方案和诊断方法均由模型在权限与硬边界内决定。
- Governance Tax：`PASS`。FAST与无验证请求的普通LOW任务相对5.17基线均为0；LOW/MEDIUM/HIGH/CRITICAL预算单调增强。
- Incrementality：`PASS`。日常产品门禁只读9个热索引文件；1000条冷历史未扫描；Design、Registry、Runtime和Evidence均有受影响范围增量路径。
- Control Precision：`PASS`。LOW=`NONE/TARGETED`、MEDIUM=`TARGETED`、HIGH/CRITICAL=`GOVERNED`；Prototype不能绕过数据、安全、破坏性操作和生产发布硬边界。

## Governance Tax 与 Verification Budget

确定性A-D场景均在风险预算内：

| 场景 | 风险控制 | 扫描 | Runtime启动 | Review | Validation | Evidence摘要 | Time-to-Accepted-Change |
|---|---|---:|---:|---:|---:|---:|---:|
| A 小UI文案 | LOW/TARGETED | 0 | 0（复用） | 0 | 1 | 1 | 0.296 ms |
| B 普通新页面 | MEDIUM/TARGETED | 0 | 0 | 0 | 3 | 1 | 0.257 ms |
| C 局部Goal Change | LOW/TARGETED | 0 | 0 | 0 | 1 | 0 | 0.080 ms |
| D 高风险发布 | HIGH/GOVERNED | 0 | 0 | 1 | 3 | 0 | `NOT_MEASURED`（需独立Assurance） |

这些数值是模块内确定性E2E，不含真实项目发现、依赖安装、实际浏览器/客户端启动、人工/模型感知审核或网络时间；相关阶段为 `NOT_MEASURED`，不得拿表内毫秒数宣称真实项目交付提速。

## 增量与证据

- Runtime复用确定性身份夹具：5次请求中2次直接复用、2次增量重载、1次因技术栈变化要求重建，复用率80%。这不是生产遥测。
- Component Registry：适配器必须给出explicit或changed scope，单次最多500文件；没有合法重建原因时完整扫描不授权。
- Evidence：键绑定source/design/project config/technology/environment/relevant state/affected scope；局部Goal Change只失效相交证据。
- Visual/Log：冷摘要只允许artifact ref、SHA-256、bytes和最多32条发现；完整Prompt、助手输出、源码、stream delta、截图二进制和原始日志被拒绝。
- Review：相同指纹PASS可复用；没有新风险、业务实现或证据时不允许继续治理循环。
