# 插件边界

| 插件 | 唯一职责 | 禁止重复承担 |
|---|---|---|
| 智能工程核心 | 技术栈识别、状态协议、规范来源、上下文生命周期 | 页面实现、Git并行、最终质量判定 |
| 浏览器端与服务端工程 | Web设计与实现；共享服务端识别、契约、迁移、实现和审核 | 客户端平台实现、全仓库状态治理 |
| 客户端工程 | 多技术栈客户端设计、实现、生命周期和平台审核，含Unity专项 | Web页面、仓库分支调度、后端实现 |
| 工作区与多会话协作 | 任务通道、子智能体、多工作目录、所有权、合并预检 | 业务实现、风险评分 |
| 质量、风险与发布 | 变更集、架构守卫、风险、图谱、测试计划、发布门禁 | 修改业务源码、创建多工作目录 |

所有插件共享 `.ai/schema.json` 的状态协议。发现协议版本不兼容时必须停止写入并报告，不得静默覆盖。
