# 插件边界

| 插件 | 唯一职责 | 禁止重复承担 |
|---|---|---|
| AI工程核心 | 技术栈识别、状态协议、规范来源、上下文生命周期 | 页面实现、Git并行、最终质量判定 |
| B/S工程 | Web设计、组件、页面和前端审核 | 重新识别全项目技术栈、Unity代码 |
| Unity工程 | Unity UI、Prefab、Renderer、资源和平台审核 | Web页面、仓库分支调度 |
| 工作区协作 | Task lane、Subagent、Worktree、所有权、合并预检 | 业务实现、风险评分 |
| 质量与发布 | 变更集、风险、图谱、测试计划、发布门禁 | 修改业务源码、创建Worktree |

所有插件共享 `.ai/schema.json` 的状态协议。发现协议版本不兼容时必须停止写入并报告，不得静默覆盖。
