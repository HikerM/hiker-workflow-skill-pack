# 01 AI工程核心

本插件是其他插件的前置底座。首次接管项目时运行“项目智能初始化”，后续领域 Skill 只读取 `.ai/context/`，不重复扫描整个仓库。长期任务使用“有界上下文记忆”：关键事实进入Task、决定、文档和Git，当前会话只加载固定大小工作集，checkpoint按近期与里程碑限额保留。

5.11 的轻量路由先识别当前主动作，再登记风险、验证、合并和发布等后续阶段。实际应用回执由 Skill 完整读取后的加载遥测生成；路由候选不能冒充已应用项。阶段变化必须先完成门禁和 Checkpoint，再重新路由。

状态与事件脚本（由 Skill 或外部编排显式调用，当前 manifest 不自动注册 Hook）：

- SessionStart：恢复当前任务、活动上下文和锁定决策；
- UserPromptSubmit：识别暂停、继续、调整、状态和回滚请求；
- PreCompact 协议：调用时保存检查点；
- Stop：记录本轮结果，不强制继续；
- SessionEnd：归档会话结束事件。
