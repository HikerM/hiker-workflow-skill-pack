# 05 质量、风险与发布

本插件负责对**真实变更集**进行只读分析，生成风险证据、回归范围、工程图谱影响和发布结论。它不负责业务实现，也不会把“建议执行的测试”写成“已通过”。

## 关键改进

- `all-local` 同时覆盖：暂存、未暂存、未跟踪文件；
- 支持新增、修改、删除、重命名和二进制文件；
- 生成目录过滤规则真正生效；
- 工程知识图谱使用 SQLite 文件级索引，不加载完整 JSON 图；
- 图谱查询强制深度与节点上限，并标注截断和索引提交；
- 测试命令从项目真实配置发现，不写死 npm、pytest 或 dotnet；
- 发布审核以证据文件为准，缺少证据时阻断或降级。
