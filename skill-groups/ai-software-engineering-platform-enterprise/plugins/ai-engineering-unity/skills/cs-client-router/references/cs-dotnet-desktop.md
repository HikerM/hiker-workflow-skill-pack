# .NET桌面客户端约束

- 从 `TargetFramework`、SDK、NuGet锁定与项目类型识别 WPF、WinUI、WinForms、Avalonia 或 MAUI 真实版本，不跨框架套模板。
- 保持既有 MVVM/事件/命令模式、依赖注入范围、Dispatcher/UI线程边界和窗口生命周期。
- View 不直接承担网络、持久化和复杂领域规则；ViewModel/Presenter 也不得演变成无限增长的万能文件。
- 绑定、命令、资源字典、导航契约和共享 DTO 属于公共表面；变化时登记消费者、兼容策略和回归测试。
- 异步调用必须传播取消与异常，避免 `async void`（事件处理器除外）、同步等待和后台线程直接触碰 UI。
- 视觉层复用语义 Token 和现有控件，验证 DPI、系统字体、键盘、无障碍、高对比度与平台窗口行为。
- 拆分依据是职责和依赖方向；小型稳定窗口不为追求“分层数量”强制增加空接口或包装层。
