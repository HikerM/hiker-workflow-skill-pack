# 嵌入式HMI约束

- 从板级配置、显示驱动、LVGL/RTOS/SDK和交叉编译清单确认版本、分辨率、色深、内存与刷新预算。
- UI、硬件抽象、通信协议和设备状态机分层；不得让页面直接操作寄存器、总线或持久化细节。
- 资源生命周期必须覆盖静态/动态内存、图像缓存、字体、DMA、线程/中断上下文和设备断连。
- 交互设计验证触控/旋钮/按键、戴手套误触、户外对比度、故障态、启动中与降级态。
- 公共协议、状态枚举、资源ID和屏幕导航表属于受保护表面，变化需锁定、版本化并做设备/模拟器回归。
- 以实际帧率、内存峰值、启动时间和输入延迟为证据；不因视觉丰富度加入超预算动效和大资源。
- 只为无法从源码推断的硬件拓扑补配置，避免维护一套与固件事实重复且易漂移的全量模型。
