# Qt客户端约束

- 从 CMake/qmake、Qt模块清单、编译器与绑定清单确认 Qt、C++/Python 和工具链版本，不把 Qt Widgets、QML、PyQt、PySide 混为一种实现。
- 沿用现有 Widgets/QML 架构、Model/View、信号槽和资源系统；跨线程对象只通过队列连接或既有调度边界通信。
- 明确 QObject 所有权、父子生命周期、线程亲和性和释放责任；不得用全局单例掩盖依赖。
- UI线程不执行阻塞I/O；后台任务必须定义取消、错误回传、退出等待和重复触发策略。
- 公共 Model、信号、序列化 DTO 或插件接口变化必须登记消费者，并运行契约与消费者回归。
- 先组合现有控件和 Design Token；新增组件需说明复用边界、DPI、字体缩放、键盘导航和多语言伸缩。
- 单文件超过预算时优先拆分状态、视图、适配器和基础设施职责，不按行数机械拆出无语义碎片。
