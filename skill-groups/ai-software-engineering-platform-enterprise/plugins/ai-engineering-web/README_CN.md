# 02 浏览器端与服务端工程

本插件不预设 Vue、React 或某个组件库。它读取项目初始化状态中的真实框架、版本、包管理器、路由、状态管理和组件库，并从当前需求、工作流、导航/路由、验收与测试映射动态发现页面和交互表面。

浏览器端能力：

- `web-ui-design`：多轮、增量的 UI 与交互设计收敛；先建立项目专属视觉方向、语义色彩、间距尺度和组件复用契约，再补齐复杂表面的数据、命令/事件、状态、并发、恢复、降级、权限、发布和可执行验收；
- `web-component-implementation`：依据已审核设计，在当前框架和组件库中实现非模板化页面；缺少设计系统、间距、色彩或组件契约时阻断编码；
- `web-quality-review`：只读审核前端结构、设计系统、组件复用、样式 Token、响应式和视觉状态，并识别普通后台骨架、Bootstrap 式默认视觉和重复卡片汤。

三项 Skill 共同禁止把“侧栏 + 顶栏 + 指标卡 + 等宽卡片网格”当作默认答案，禁止照搬 Bootstrap 式蓝色按钮、灰底白卡和统一圆角阴影，也禁止每个区块都套同形卡片。项目确实依赖 Bootstrap 时可以保留技术兼容，但必须通过项目 Token 和组件层形成独立视觉语言。

服务端能力：

- 「服务端技术路由」：从工程清单识别真实框架、运行时、包管理器和版本；
- 「接口与事件契约设计」：串行定版公共API、事件、错误、权限和消费者兼容规则；
- 「服务端功能实现」：在现有领域边界、事务和契约内实现单一功能；
- 「数据库迁移治理」：控制Schema、数据迁移、兼容窗口、校验和回滚；
- 「服务端质量审核」：独立审核服务端、契约、迁移、并发、鉴权、可观测性和恢复证据。

B/S与C/S共享同一服务端能力，客户端插件不复制后端规则。服务端阶段同样采用轻量路由，每轮只加载当前技术族和当前阶段需要的原子能力。

`web-ui-design` 还会检查用户可见信息与内部标识隔离，以及编辑、阅读、审核、发布模式的一致性。设计自检不能替代质量插件中的独立设计就绪复审。
