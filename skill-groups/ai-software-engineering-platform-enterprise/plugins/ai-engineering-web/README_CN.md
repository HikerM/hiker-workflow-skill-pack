# 02 B/S界面与前端工程

本插件不预设 Vue、React 或某个组件库。它读取项目初始化状态中的真实框架、版本、包管理器、路由、状态管理和组件库，并从当前需求、工作流、导航/路由、验收与测试映射动态发现页面和交互表面。

包含：

- `web-ui-design`：多轮、增量的 UI 与交互设计收敛；普通页面采用标准深度，高复杂度表面补齐类型化数据、命令/事件、状态、并发、恢复、降级、权限、发布和可执行验收；
- `web-component-implementation`：依据已审核设计，在当前框架和组件库中实现页面；
- `web-quality-review`：只读审核前端结构、组件复用、类型、样式 Token、响应式和视觉状态。

`web-ui-design` 会检查用户可见信息与内部标识隔离，以及编辑、阅读、审核、发布模式的一致性。设计自检不能替代质量插件中的独立设计就绪复审。
