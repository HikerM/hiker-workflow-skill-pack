# 服务端功能实现

实现前读取变更契约、真实技术版本、现有能力基线、API/事件契约、数据库影响、权限和最低测试。

只修改授权模块；复用现有领域服务、仓储、错误模型和日志规范。公共表面变化必须先登记消费者。完成后运行项目真实格式化、静态检查、单元、集成和契约测试，并记录命令、退出码、Git提交和工作区指纹。

正式运行路径不得默认启用 Demo、Mock 或 Fixture，不得把测试账号、样例身份、本机路径、堆栈、数据库内部错误或敏感配置回传给客户端。临时迁移实现必须声明唯一权威写入者、退出条件和删除 Gate，禁止长期保留多个版本服务共同接收新需求。
