# 服务端质量审核

先运行 `python <plugin-root>/scripts/backend_guard.py --root . audit`，再读取完整变更集、任务契约、消费者和真实测试证据。

重点检查职责边界、公共契约兼容、事务与并发、权限、错误模型、超时重试、队列幂等、迁移回滚、日志指标、资源使用和部署恢复。缺少真实运行时版本、消费者回归、迁移验证或回滚证据时不得判定通过。

同时检查同一能力是否存在多个活动入口或权威写入者、废弃版本是否仍承载新增需求，以及正式运行路径是否默认启用 Demo/Mock/Fixture或向客户端暴露内部诊断。发现任一项不得判定发布就绪。
