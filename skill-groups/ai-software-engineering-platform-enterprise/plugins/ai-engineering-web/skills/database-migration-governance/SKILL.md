# 数据库迁移治理

迁移前确认数据库类型与版本、当前Schema版本、数据规模、停机预算、应用兼容窗口和备份恢复路径。

迁移必须串行编号，包含前向步骤、回滚或补偿方案、旧应用兼容性、数据校验、失败恢复和生产前演练证据。已经进入共享环境的迁移不得重写历史；使用新的修正迁移。
