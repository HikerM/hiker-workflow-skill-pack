# B/S组件与页面实现

## 实现前

1. 读取 `.ai/context/tech-stack.json`；
2. 运行 [component_registry.py](../../scripts/component_registry.py) 更新组件清单；
3. 读取页面规格、API契约和锁定决策；
4. 输出影响文件、复用组件、新增组件理由和验证命令。

## 分层

```text
页面
→ 业务组件
→ 组合组件
→ 基础组件
→ 当前项目组件库
```

禁止：

- 页面直接散落 `fetch/axios`（除非项目架构明确允许）；
- 公共组件依赖具体业务模块；
- 复制整页形成新功能；
- 未评估新增生产依赖；
- 硬编码颜色、字号、间距、圆角；
- 把页面临时状态全部塞入全局 Store。

## 连续执行

普通实现步骤连续完成并自动保存检查点。用户中途调整时只重做受影响部分，不丢弃已完成的服务、类型或测试。

## 完成证据

构建、类型检查、测试、目标分辨率截图、控制台错误、修改文件和未验证范围。
