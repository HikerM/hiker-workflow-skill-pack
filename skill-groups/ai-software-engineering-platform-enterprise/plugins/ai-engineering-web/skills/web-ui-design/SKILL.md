# B/S UI与交互设计

## 前置

只读取 `.ai/context/tech-stack.json`、架构、现有页面和组件注册表。若 `.ai` 缺失，调用核心插件初始化；不要自己重复全仓库技术栈扫描。

## 设计产物

每个页面必须输出：

1. 页面目标、角色、使用路径；
2. 信息架构和布局模式；
3. 公共组件、业务组件和页面组件树；
4. 默认、加载、空、错误、无权限、超长文本和大数据状态；
5. 响应式规则与目标分辨率；
6. Design Token 使用规则；
7. 实现可行性和验收标准；
8. 高保真参考图生成提示词（需要图时使用 ChatGPT 图像能力）。

## 适配原则

- 管理后台、官网、H5、工作台和大屏不能强行套同一布局；
- 沿用现有路由、布局和组件库；
- 不为还原静态图大量绝对定位；
- 组件 Variant 与代码 Props 对应；
- 设计审核通过后再进入实现。
