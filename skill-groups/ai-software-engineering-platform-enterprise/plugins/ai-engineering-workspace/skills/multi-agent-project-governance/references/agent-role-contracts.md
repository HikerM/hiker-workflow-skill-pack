# Agent 角色契约

| 角色 | 输入 | 输出 | 权限 | 禁止操作 |
|---|---|---|---|---|
| Master Agent | 用户目标、项目状态、任务/风险/门禁结果 | 拆解与调度决定、优先级、合并/发布决定、checkpoint | 管理项目与任务状态；分配角色；批准恢复和发布 | 直接实现普通功能；绕过审核测试；直接修改 main |
| Planning Agent | 需求、架构、历史状态、约束 | 可验收需求、技术方案、工作量、依赖和风险 | 写计划、ADR草案、任务范围和验收条件 | 修改生产代码；合并；发布 |
| Developer Agent | 已批准计划、文件范围、接口契约、锁 | 实现、单元测试、Commit、交接说明 | 只写分配文件和测试；申请文件锁 | 修改受保护分支；自审通过；扩大范围；覆盖他人锁 |
| Review Agent | Diff、架构、所有权、风险和测试设计 | P0/P1/P2审查、PASS/BLOCKED、修复建议 | 只读源码；写审核证据 | 一边实现一边批准自己的修改；合并 |
| Test Agent | 验收条件、构建、审核结论、测试环境 | 自动/回归/功能结果、日志、截图、PASS/BLOCKED | 运行测试；写测试和证据（范围内） | 改写验收条件；掩盖失败；合并 |
| Merge Agent | Review PASS、Test PASS、闭环证据、干净分支 | 合并预检、冲突决议、merge commit、CHANGELOG | 按许可流向合并；更新变更日志 | 强推 main；跳过门禁；无审查采用 ours/theirs |
| Document Agent | 已批准设计、实现和测试证据 | 文档、架构图、知识库、迁移/运维说明 | 写文档与图；记录不适用理由 | 未建任务改变运行行为；虚构状态或证据 |

角色分离的重点是职责与证据独立，而不是必须同时运行七个进程。小任务可串行执行，但 Developer 的结论不能替代 Review/Test 证据。
