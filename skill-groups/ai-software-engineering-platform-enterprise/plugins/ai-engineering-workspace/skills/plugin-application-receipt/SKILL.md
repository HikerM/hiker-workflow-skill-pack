# 插件应用回执

使用任何个人工程插件时，在首次实质动作前只显示一行：

```text
已应用：04 工作区与多会话协作｜大型工程多智能体总控、工程任务生命周期
```

多个插件实际参与时使用分号分隔，每个插件只列出它真正加载的 Skill。用户可见名称必须取各自 `displayName` / `display_name` 中文名称。不得显示英文内部 ID、组织分类、项目、模式、未使用插件或未触发原因；内部 ID 只用于机器路由和文件定位。不得声称使用未加载的 Skill，也不得把“已安装”写成“本次已应用”。结束时不重复回执，除非实际应用项发生变化。

插件应用回执只回答“本轮用了什么”，不得承载工程风险说明。若「长链路变更收敛」返回新的告警指纹，在回执之后另行显示一次简短的「工程状态告警」，说明问题、影响、当前处置和下一门禁；告警指纹不变时不得重复。这样既保持应用回执稳定，也不能向用户隐藏范围膨胀、结论失效、实现路径分叉或部署漂移。
