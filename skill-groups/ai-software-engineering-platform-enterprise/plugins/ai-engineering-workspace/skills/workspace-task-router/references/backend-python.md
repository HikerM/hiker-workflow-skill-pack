# Python 后端

只在技术栈证据命中 FastAPI、Django、Flask、SQLAlchemy、Pydantic 或 Python 服务时读取。

- 锁定 Python、框架、依赖管理器和已解析依赖版本；保持同步/异步模型与现有应用工厂或设置边界。
- Route/View、Schema、Service/Use Case、Domain、Repository、Task 和外部 Provider 职责分离。
- Pydantic/Serializer、OpenAPI、认证授权、Celery/队列消息和 Alembic/Django Migration 采用单写所有权。
- 验证异步阻塞、事务会话生命周期、N+1、幂等、重试、时区、序列化和错误映射。
- 只运行项目真实的格式、类型、lint、单元、集成、契约与迁移命令；未配置的门禁明确列为缺口。
