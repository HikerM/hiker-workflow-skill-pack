# Skill 变更日志

## 1.1.0 - 2026-08-01

### 新增

- G1-T 原软件技术指纹与证据边界。
- G4-C 覆盖完整性门禁：入口、窗口、页面、控件、功能、角色、异常、外部依赖和发现轮次库存。
- G5-T 技术栈与精确版本门禁：源码技术探测、候选评分、代表性 POC、平台兼容、官方文档索引、依赖锁和工具链验证。
- G9-D 交付物完整性门禁：交付清单、文件状态、SHA-256 和全门禁汇总。
- 端到端追踪、覆盖率计算、孤立项检测和残余未知风险报告。
- 完整 v1.1 项目目录、112 个模板文件、17 个 Python 工具脚本、跨平台安装脚本和 Skill 自检。
- 中文命令：自动识别工程技术栈、锁定编程语言和版本、检查功能遗漏、执行全门禁、生成完整交付包。

### 修改

- 区分原软件技术指纹与目标技术选型，禁止将黑盒推断当作精确版本事实。
- 项目初始化目录升级为控制、环境、证据、库存、规格、技术设计、实现、测试、构建、报告和交付十一类。
- 发布结论必须同时满足覆盖、工具链、性能、缺陷和交付物门禁。
- 安装说明按当前 ChatGPT 桌面端与 Codex 的 Skills 发现方式更新。

### 兼容性

- Skill 名称保持 `desktop-app-reconstruction-zh`，可覆盖安装 v1.0.0。
- v1.0 项目不会自动修改；建议备份后使用新初始化目录迁移。
