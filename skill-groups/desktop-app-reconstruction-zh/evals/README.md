# Skill 评测集

`skill-evals.jsonl` 包含中文触发、技术版本、遗漏审计、权限边界、恢复执行和交付门禁场景。每行由 `prompt`、可选 `context`、`expected.must` 与 `expected.must_not` 组成。

建议评测流程：

1. 分别在未安装 Skill 与安装 Skill 的环境执行同一提示；
2. 保存运行轨迹、命令、文件产物和最终答复；
3. 先执行确定性检查，再按 `skill-rubric.schema.json` 进行结构化评分；
4. 对比版本间的触发率、门禁遵守率、错误完成声明、命令重复和残留文件；
5. Skill、模板或脚本变更后至少重跑 EVAL-001、002、004、007、009、010、012。

这里的评测验证 Skill 行为，不替代真实目标软件的业务验收。
