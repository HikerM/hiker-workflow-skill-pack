# 03 证据采集规范

## 1. 证据类型

- 截图：窗口、页面、菜单、弹窗、控件状态、多 DPI；
- 录屏：完整流程、动画、拖拽、滚动、快捷键、取消和恢复；
- 操作日志：前置条件、步骤、输入、实际结果和重复次数；
- 控件树：类型、名称、层级、状态、自动化 ID 和焦点；
- 样例文件：有效、无效、旧版本、大文件、边界和损坏数据；
- 文件/数据库/配置差分：操作前后变化；
- 性能样本：环境、时间戳、场景、重复次数和原始指标；
- 安装与系统证据：进程、服务、文件关联、注册项、日志和卸载残留；
- 网络时序：仅在授权范围记录公开接口、状态码、时序和重试，避免敏感正文。

## 2. 目录与只读原则

原始证据放入：

```text
02_evidence/raw/
```

分析、裁切、遮罩和转换产物放入：

```text
02_evidence/processed/
```

不得覆盖原始证据。每个文件使用 SHA-256，索引写入 `02_evidence/EVIDENCE_INDEX.csv`。

## 3. 命名示例

```text
EV-20260801-0001_login_normal_WIN11_1920x1080_100.png
EV-20260801-0002_import_invalid_file.mp4
EV-20260801-0003_cold_start_ENV-0001.csv
```

## 4. 每项证据字段

- evidence_id；
- file_path；
- evidence_type；
- captured_at；
- source_app_version；
- environment_id；
- operator；
- action_or_state；
- sha256；
- related_ids；
- classification；
- privacy_level；
- notes。

## 5. 核心页面采集矩阵

检查适用项：默认、加载、有数据、空数据、校验失败、服务错误、权限不足、禁用、菜单/弹窗、悬停、聚焦、选中、编辑、未保存、最小/默认/最大窗口、目标 DPI 和多显示器。


## 7. 质量要求

- 关键结论至少一个直接证据，高风险规则使用多个独立证据；
- 截图保留原分辨率和 DPI，不二次压缩；
- 录屏显示鼠标、窗口边界、等待和完整反馈；
- 动态内容、个人信息和密钥先脱敏或建立视觉遮罩；
- 没有来源的口述需求标记 `UNVERIFIED`；
- 证据受阻时记录原因和补证动作，不猜测。
