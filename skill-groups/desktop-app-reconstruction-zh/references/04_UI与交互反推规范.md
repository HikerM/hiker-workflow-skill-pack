# 04 UI、入口与交互反推规范

## 1. 先建立入口和窗口地图

入口包括桌面快捷方式、文件关联、命令行、协议链接、开始菜单、主菜单、工具栏、右键、托盘、通知、快捷键、拖拽和外部回调。

窗口包括主窗口、子窗口、模态/非模态对话框、浮层、托盘菜单、系统通知、首次启动、更新、错误和恢复界面。

每个入口/窗口必须有唯一 ID、证据、权限、前置状态和范围优先级。

## 2. 页面规格字段

- page_id、名称、窗口和入口；
- 角色、权限、数据和服务前置条件；
- 布局区域、锚点、最小/最大尺寸、自适应规则；
- 控件类型、文本、图标、可见性、启用条件和自动化标识；
- 字体、字号、字重、行高、颜色、换行/截断；
- 间距、圆角、阴影、边框、层级和滚动；
- 正常、加载、空态、错误、禁用、悬停、聚焦、选中、编辑和弹窗状态；
- 动画时长、缓动、触发、中断和帧率；
- 键盘导航、焦点顺序、快捷键和可访问性；
- 多分辨率、DPI、主题、多显示器和系统缩放。

## 3. 几何记录

同时保存：

- 基准绝对像素；
- 相对比例、锚点和约束；
- 内容区与系统窗口装饰边界；
- 分辨率、DPI、缩放和字体渲染环境。

不要用大量固定坐标维持界面。反推真实布局规则，如侧栏固定/可折叠、内容自适应、最小宽度、网格和滚动容器。

## 4. 控件库存

每个可交互控件写入 `INTERACTIVE_CONTROL_INVENTORY.csv`：

- 所属页面；
- 控件类型和标签；
- 是否可交互；
- 可见/启用条件；
- 适用状态；
- 关联交互 ID；
- 证据和规格；
- 当前验证状态。

页面上出现但不可交互的重要状态控件也应登记，以便视觉和可访问性验收。

## 5. 动态行为

逐段确认页面切换、菜单、弹窗、列表虚拟化、拖拽、缩放、吸附、骨架屏、进度、通知、动画时序和取消响应。静态截图无法确认的内容标记 `UNVERIFIED`。

## 6. 视觉验收

分别检查：结构、关键区域几何、文本、控件状态、图标语义、颜色/间距、动态遮罩、多 DPI、动画和人工复核。字体抗锯齿和系统渲染差异不能用扩大容差掩盖布局错误。
