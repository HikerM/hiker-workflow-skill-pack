# 05 功能、数据、权限与恢复反推规范

## 1. 功能使用 I-P-O-S-R 模型

- `Input`：输入、来源、类型、范围、默认值；
- `Process`：校验、转换、计算、状态机、权限和事务；
- `Output`：界面、文件、接口、打印、导出和通知；
- `Side effects`：数据库、缓存、配置、日志、网络、最近记录和系统变化；
- `Recovery`：取消、超时、重试、回滚、崩溃后恢复和幂等。

## 2. 核心功能最低场景

- 正常路径；
- 非法输入和异常路径；
- 最小/最大/空值/重复等边界；
- 不同角色与后端权限；
- 保存、重启和升级后的持久化；
- 中断、取消、超时、重试和失败回滚；
- 文件占用、磁盘不足、网络断开、服务失败；
- 大文件、大数据、快速重复操作和多窗口冲突。

## 3. 状态机示例

```yaml
interaction_id: "INT-0018"
preconditions:
  - "user.logged_in == true"
  - "project.dirty == true"
trigger:
  type: "click"
  target: "CTRL-0047"
processing:
  - "validate_project"
  - "write_atomically"
success:
  - "project.dirty = false"
  - "show_success"
failure:
  - "keep_dirty = true"
  - "show_error_code"
  - "offer_retry"
recovery:
  - "restore_backup_on_partial_write"
```

## 4. 数据契约

文件、数据库、接口、消息、缓存和配置至少记录：

- 格式、版本、编码、时区、区域和小数规则；
- 必填、可空、默认值、枚举、唯一性和排序；
- 分页、幂等、并发、事务和错误码；
- 迁移、向后兼容、备份、恢复和损坏检测；
- 敏感字段、脱敏、保留和访问权限。

不得用少量样例宣称完整恢复私有格式。未知字段保留为未知并设计更多样本或合法兼容层。

## 5. 权限

每项功能明确：

- 哪些角色可见；
- 哪些角色可执行、只读或禁止；
- 禁止时的反馈；
- 是否在后端/领域层再次校验；
- 越权调用、旧会话和缓存权限变化后的行为。

只隐藏按钮不等于权限正确。

## 6. 外部依赖

对云服务、SDK、设备、数据库、许可证服务和本地服务记录版本、授权、认证、超时、重试、离线行为、降级、替代和许可。不可获得时必须明确：官方 API、适配层、等价替代、范围差异或阻断，不得伪造成功结果。
