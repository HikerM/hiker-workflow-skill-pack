# 09 桌面自动化、Computer Use 与 MCP 约定

## 1. 分工

Skill 定义流程、证据、判断和输出；Computer Use 或桌面 MCP 提供受控的窗口、鼠标、键盘、截图、控件树、进程和文件操作。Skill 本身不会自动获得本机权限。

结构化 MCP 可用时优先于纯视觉点击；只有 GUI 可观察时使用 Computer Use。

## 2. 最小工具能力

### 会话和白名单

- 开始/结束会话；
- 允许的进程、应用和目录；
- 只读/可写模式；
- 操作审计和证据返回。

### 窗口与观测

- 列出、聚焦、调整窗口；
- 截取窗口/区域、录屏；
- 读取可访问性树、焦点和控件状态；
- 等待明确状态而非固定盲等。

### 输入

- 点击、双击、拖拽、滚动；
- 键盘输入和快捷键；
- 文件选择和对话框处理；
- 取消和恢复。

### 进程与性能

- 启动/停止指定进程；
- 采样 CPU、内存、GPU、磁盘和网络；
- 读取授权日志；
- 记录崩溃和子进程。

### 文件变化

- 白名单目录快照、监控和差分；
- 不访问项目无关目录；
- 凭据和个人数据脱敏。

## 3. 操作事务

1. 记录环境、前置状态和证据；
2. 聚焦授权窗口；
3. 截图/读取控件树；
4. 执行动作；
5. 等待可验证条件；
6. 截图并读取结果；
7. 记录数据、文件、日志和性能副作用；
8. 失败时恢复安全状态并登记缺陷/受阻。

## 4. 权限边界

- 默认只读；
- 删除、覆盖配置、账号变更、付款、发布、安装驱动和停止系统服务需明确批准；
- 不读取项目无关窗口、剪贴板、密码、令牌和文件；
- 不绕过登录、许可证、DRM、安全软件或审计；
- Windows 前台操作会占用鼠标键盘，应保持目标应用可见；
- 每个操作产生时间、参数摘要、结果和证据。

## 5. 推荐 MCP 返回结构

```json
{
  "ok": true,
  "session_id": "...",
  "timestamp": "2026-08-01T10:00:00+08:00",
  "result": {},
  "evidence": [
    {"type": "screenshot", "path": "...", "sha256": "..."}
  ],
  "warnings": [],
  "error": null
}
```

## 6. 禁止暴露

任意进程注入、权限绕过、凭据导出、未经授权全盘搜索、隐蔽键盘记录、后台屏幕监控、许可证/DRM 绕过和无审计破坏性操作。
