# 10 中文命令与使用示例

## 1. 新建项目

```text
@桌面软件等价重建
开始新项目。
目标软件：XXX 3.2，Windows 11。
目标：重建 Windows 10/11 x64 版本，核心流程、UI、文件输出和性能达到约定等价，品牌素材使用自有资源。
现有材料：安装包、测试账号、录屏、样例文件和空源码目录。
先完成授权、材料、环境和范围，不要直接写代码。
```

## 2. 自动识别已有工程

```text
自动识别工程技术栈。读取当前源码目录中的项目清单、锁文件、构建脚本和 CI，输出语言、框架、SDK、编译器和版本证据。不要根据文件扩展名直接下结论。
```

## 3. 锁定语言和版本

```text
锁定编程语言和版本。先读取 TARGET_CONSTRAINTS、平台矩阵和候选评分，核验对应版本官方文档，完成代表性 POC，再生成 TECH_STACK_DECISION 和 TECH_STACK_LOCK。禁止使用 latest 或模糊版本。
```

## 4. 只有截图/录屏

```text
分析这些截图和录屏。输出入口、窗口、页面、控件、状态和交互库存；明确能确认、推断、未验证和需要补拍的内容。
```

## 5. 反推功能

```text
反推“导入项目”。整理输入、校验、处理、输出、副作用、权限、错误、回滚、持久化、性能场景和测试用例，并更新功能库存和追踪矩阵。
```

## 6. 检查遗漏

```text
检查功能有没有遗漏。遍历所有入口、页面、菜单、快捷键、角色、数据状态、异常和安装流程，更新 DISCOVERY_ROUNDS；执行覆盖、追踪和孤立项检查，不能只给主观结论。
```

## 7. 进入实现

```text
读取当前项目状态。仅在 G0、G1、G2、G3、G4-C 和 G5-T 通过后，按 TASK ID 实现第一个真实端到端闭环。禁止生成静态演示页和假接口。
```

## 8. 给 Codex 的任务包

```text
把冻结规格拆成 Codex 可执行任务。每个任务写明关联 ID、修改文件、禁止范围、依赖、测试命令、验收、证据和回滚点。
```

## 9. 一致性审核

```text
使用同一环境、账号、数据和操作脚本，对原软件和候选软件执行视觉、功能、数据和性能差分。生成 P0-P3 缺陷，不得只看整页相似度。
```

## 10. 全门禁和交付

```text
执行全门禁。运行结构、工具链、覆盖、追踪、孤立项、交付物和发布检查；失败时保留报告并修复真实问题。
```

```text
生成完整交付包。按当前模式完成 DELIVERABLE_MANIFEST 中的必需项，计算 SHA-256，生成发布就绪报告。
```

## 11. 继续上次工作

```text
继续。读取 PROJECT、STATUS、DECISIONS 和当前门禁，从唯一未完成主动作继续，不重复完成项。
```
