# 11 输出协议与标准项目目录

## 1. 会话回复协议

除极短问答外，每轮按以下结构报告：

```text
1. 本轮完成
2. 证据与结论等级
3. 新增或修改文件
4. 门禁结果
5. 未验证、受阻和残余风险
6. 下一步唯一主动作
```

禁止使用“应该没问题”“基本一样”“都实现了”“性能肯定更好”等无证据表述。

## 3. 六类最终成果

1. **反推证据**：环境、截图、录屏、样例文件、操作日志、配置/文件差分和性能原始数据；
2. **软件规格**：页面、控件、交互、功能、数据、权限、异常和性能规格；
3. **技术方案**：源技术指纹、目标候选、精确版本锁、架构、接口、数据库和构建方案；
4. **实现成果**：源码、资源、配置、迁移、适配层、依赖锁和自动化测试；
5. **发布成果**：安装、升级、卸载、迁移、回滚、SBOM、许可证和校验值；
6. **验收成果**：覆盖、追踪、差分、性能、稳定性、缺陷、风险和发布准备报告。

## 4. 按模式输出

- **资料分析**：必须完成 00–05、07 中的测试设计、09 中的规格/覆盖/风险报告；实现和安装产物标记为条件不适用，但不能声称完成软件。
- **代码实施**：增加 06、单元/集成/UI 自动化、依赖锁和构建配置。
- **自动观测**：增加操作重放、控件树、处理证据、自动差分和性能采样。
- **混合/发布**：在范围要求下完成 08、09、10，并通过安装、升级、卸载、迁移和回滚。

## 5. 状态同步

每轮更新 `STATUS.yaml`、`DECISIONS.md`、`CHANGELOG.md`、相关库存、追踪矩阵、测试结果和交付清单。项目事实以文件为准，聊天仅作为当前协作界面。
