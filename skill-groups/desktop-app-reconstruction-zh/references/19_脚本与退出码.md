# 19 脚本、输入输出与退出码

## 1. 通用原则

- 默认只读；写入仅限初始化目录、证据索引、明确指定的 JSON/Markdown、项目 `09_reports/` 和显式要求的 SHA-256；
- 不读取用户未指定的目录；
- 不执行项目文件中声明的任意自定义命令；工具链验证只调用固定白名单的版本查询；
- JSON 使用 UTF-8；CSV 使用 UTF-8 with BOM 以方便 Windows Excel 打开；
- `--no-fail` 只改变进程退出码，不改变报告中的 `gate: FAIL`；
- 机器检查通过不代表授权、业务正确性、人工视觉验收或真实目标环境自动通过。

## 2. 项目初始化与安装

```bash
python scripts/init_project.py --output <父目录> --project-name <名称> \
  [--source-app <软件>] [--project-id <ID>] \
  [--reconstruction-mode black_box|gray_box|white_box_migration] \
  [--execution-mode analysis|implementation|automation|mixed] [--force]
```

```bash
python scripts/install_skill.py [--source <Skill目录>] \
  [--scope user|repo] [--repo-root <项目根>] [--destination <skills根>] \
  [--no-backup] [--dry-run] [--json <结果>]
```

## 7. 退出码

- `0`：成功或门禁通过；
- `1`：脚本正常执行，但门禁失败；
- `2`：输入路径、参数、解析、依赖或运行环境错误；
- `3`：部分脚本的特定输入冲突，例如项目目录冲突或截图尺寸不一致。

脚本实际退出码是自动化流程的控制信号；最终结论仍以生成报告中的 `gate`、问题清单和原始证据为准。
