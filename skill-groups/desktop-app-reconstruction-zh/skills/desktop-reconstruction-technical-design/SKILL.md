# 桌面重建技术方案

先确认G0–G4-C已通过，仅读取共享包 `references/14_技术栈选型与版本锁定规范.md`、当前约束和技术指纹。原软件技术与目标技术分开记录。

执行“目标约束 → 候选路线 → 官方版本核验 → 代表性POC → 性能/安装验证 → 决策 → 精确锁定”。产出候选矩阵、决策、版本锁、官方文档索引、依赖清单和技术验证报告。禁止以 `latest`、`stable`、`LTS` 作为最终版本。

只在需要时运行 `validate_toolchain.py`。没有真实POC、安装验证、精确版本或对应版本官方资料时，G5-T不得通过，也不得路由到实现。
